# kairos-midia

Mídias de publicação do Instagram @kairoslicitacao.

## Estrutura
- `midia/` — arquivos publicáveis (URLs raw usadas pelo Metricool).
- `estudio/` — motor de render aprovado (HTML animado + Playwright + ffmpeg + trilhas originais).
- `skill/kairos-instagram-growth/` — skill de gestão do Instagram (SKILL.md, referências, templates, scripts).
- `operacao/` — estado vivo: ESTADO.md, plano V2, calendário, controles de conteúdo, Boost, KPIs, ideias, experimentos, leads, aprovações.
